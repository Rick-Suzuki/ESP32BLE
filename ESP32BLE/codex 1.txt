2. Automatic table scroll

The canonical identity is now consistent:

• Set_Screen.swift:3223-3232
   • Navigation resolves a collection URL.
   • It stores selectedTemplateURL.path in templateScrollPositionIDStorage.

• Set_Table.swift:160-161 and 1045

Therefore the navigation-written scroll ID and row IDs now use the same raw collection path. This is not a remaining URL representation mismatch.

The source-level scrolling issue is timing:

• Set_Table.swift:180-183
   • The only explicit ScrollViewReader restoration task runs from selectionRestorationID.

• Set_Table.swift:487-490
   • selectionRestorationID contains only listMode and active row paths.
   • It does not contain selectedTemplateURL or selectedRowPath.

• Set_Table.swift:555-566
   • restoreSelectedRowVisibility(using:) can scroll the selected template row.
   • But it does not rerun when Back, Previous, Next, Random, or table selection changes only the selected template.

The existing scrollPosition binding is valid and SwiftUI supports writing an ID binding to request scrolling. However, the table does not have a deterministic explicit ScrollViewReader response to a Templates selection change after the rows already exist. The direct binding can be overwritten by List’s top-visible-row reporting or fail to provide the required timing guarantee during selection updates.

Make selectionRestorationID include the selected template row identity only when listMode is Templates. This causes the existing task at Set_Table.swift:180 to rerun and call the already-existing restoreSelectedRowVisibility(using:) after a Templates selection change.

This is smaller and safer than adding a second selection state, selection index, or new scrolling mechanism. It preserves every other category’s existing restoration behavior.

For highlight, do not add a second selection state or change table styling until a focused runtime diagnostic confirms whether the table receives a non-nil selectedTemplateURL. The existing comparison and yellow precedence are already correct.
