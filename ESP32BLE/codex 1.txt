3. Why the red controls are larger

Top toolbar:
• “file”, “KB”, “edit”, and “done” have no active .font modifier.
• The commented-out .headline modifiers do nothing.
• No parent font modifier changes them.
• They therefore use SwiftUI’s default body typography: normally about 17 points at the default Dynamic Type size, with Dynamic Type scaling.

Bottom numeric values:
• Column count, row count, and box-font-size value all use .headline.
• .headline is normally about 17 points, semibold, and Dynamic-Type-scaled.
• The “13” box-font-size label additionally permits scaling down to 85% only when constrained.
• The “10” and “6” labels do not have a minimum scale factor.

Therefore the visible discrepancy is deliberate source typography:
• Reference controls: fixed 14-point regular.
• Top labels: default scalable body, normally approximately 17 points.
• Numeric values: scalable headline, normally approximately 17-point semibold.

It is not caused by button dimensions, icon sizes, or an inherited toolbar font.
