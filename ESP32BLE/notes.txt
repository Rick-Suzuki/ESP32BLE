.midi <note> [velocity] [channel] [toggle]
.cc <controller> <value> [channel] [hold|toggle]


.midi 60
.midi C3 100
.midi F#4 127 2
.midi 60 120 1 toggle

.cc 7 100
.cc 64 127 1 hold
.cc 64 127 1 toggle


Notes accept MIDI numbers 0...127, or note names such as C3, F#4, and Bb2.
• Note velocity is optional (1...127) and defaults to 127.
• MIDI channel is optional (1...16) and otherwise uses the app’s default MIDI channel.
• .midi without toggle is momentary: Note On while pressed, Note Off on release. toggle alternates on/off per press.
• .cc controller and value are both 0...127.
• Plain .cc sends once. hold sends the value while pressed, then sends 0 on release. toggle alternates between the value and 0.


The app provides friendly labels for commonly used CCs including bank select (0), modulation (1), volume (7), pan (10),
expression (11), sustain (64), reverb (91), chorus (93), all sound off (120), reset controllers (121), and all notes off (123).
Any valid CC number from 0...127 is accepted.
