5. Centralized relocation recommendation

A small centralized loader change is practical.

Keep every existing SwiftUI page manifest unchanged. Adapt ESPHelpHTMLView.pageResources(named:) at 7036-7055 so it routes:

• Quick Help filenames to Help/html/<filename>
• complete-user-manual.html to Help/manual/complete-user-manual.html

• Connect to Mac preload.
• Manual presentation.

The one deliberate exception is the manual: it should be independently portable, but the app may still grant Help-root read access without preventing the manual from being self-contained.

7. Missing-image fallback recommendation

CSS alone cannot detect a failed image request or display its filename.

Recommended minimal convention:

• Add one small local shared JavaScript helper.
• Every Help image uses the existing img element and invokes the helper through onerror, or the helper scans images after document load.
• On failure, replace or hide the broken image and show:
Image file not found: filename.ext
• Style the fallback with a shared CSS class retaining the existing centered, bounded presentation.

For the portable manual, the generator should either:

• Rewrite each image to use the same shared local helper packaged in Help/manual, or
• Emit a short inline helper directly into the generated manual.

The inline generated-manual option is the least fragile portable design. Quick Help still needs a shared helper file or a small inline helper in each source page. A shared Help/js/help-images.js plus a copied Help/manual/js/help-images.js is more maintainable.

11. Regression risks

Highest risks:

• If the app loader’s read-access URL remains Help/html, ../css and ../images will fail.
• If only the manual HTML is moved, but its CSS/images are not copied, website/local-browser use fails.
• If the generator only changes source directory but not image resolution, it will report valid source images as missing.
• If copied manual assets retain source paths such as ../images, the manual will not be portable.
• If resource membership is file-by-file rather than folder-based, new folders may not enter the app bundle.
• The existing preload specifically names connect-mac.html; preserve its centralized resolution.
• Do not alter the existing native Help toolbar, iPhone bottom layout, iPad form sheet, or manual scroll controller.
• Test both iPhone landscape and iPad sheet/full-screen paths on physical devices only.
