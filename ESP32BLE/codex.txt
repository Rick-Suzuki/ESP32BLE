B. POPUP IMPLEMENTATION

Added a small popup mode state:

Action popup
Resize popup

Tapping the purple Resize icon switches the existing popup target into Resize mode. The Resize popup reuses the same 146x146 size, position calculation, black background, border, clipping and corner radius.

The X cell returns to the normal action popup without dismissing selection or changing the grid.

C. GRAPHICAL SIZE BUTTONS

Added a second 3x3 popup with this layout:

X, 1x1, 2x1
3x1, 1x2, 2x2
3x2, 1x3, 3x3

Each size cell draws a proportional mini rectangle grid in purple plus a compact white size label. No emoji, images or assets were added.

D. CURRENT SIZE HIGHLIGHT

The current selected button size is highlighted in purple inside the Resize popup.

After successful resize, the selected button frame is refreshed and the highlight updates with the current grid state.

Same-size selection is a no-op.

E. RESIZE VALIDATION

Popup resize validates the full requested footprint.

Allowed:

Cells already belonging to the selected button
Empty cells

Rejected:

Out-of-bounds footprint -> “Not enough space”
Cells occupied by another button -> “Space occupied”

The selected button’s own continuation markers are not treated as obstacles.

F. ATOMIC PERSISTENCE

Resize builds a complete updated raw slot-line array in memory.

It clears the old footprint, preserves the anchor rawLine exactly, writes new continuation markers, and persists once through the existing complete-grid restore path.

No repeated per-cell persistence was added.

G. UNDO

Each successful resize records one existing popup Undo snapshot.

No new Undo stack was added.
Duplicate’s special Undo selection restoration remains preserved.
Clipboard is not modified by Resize.

H. POPUP POSITIONING

The Resize popup uses the existing popup positioning path.

After successful resize, the cached selected-button frame is recalculated from the old frame, grid spacing and new width/height so the popup remains attached to the resized button.
