3. Effective channel resolution

The automatic label parses the existing MIDICommand and calls:

MIDIChannelSettings.resolvedChannel(
for: midiCommand,

defaultChannel: defaultMIDIChannel

)

This preserves:

Explicit command override first.
Valid device default second.
Safe channel 1 fallback last.

The generated label is:

<noteDisplayName>

Ch <effective channel>

4. Settings updates

MainScreen already observes MIDIChannelSettings.storageKey through @AppStorage.

That observed value is now passed into the label-generation path. Changing the default channel causes SwiftUI to recalculate labels that do not have explicit overrides.

Explicit command channels remain unchanged by Settings changes.

5. Label precedence

Existing precedence remains intact.

Custom right-hand text, SF Symbols, SF Symbols with subtitles, and emoji continue to suppress the automatic fallback.

Whitespace-only and color-only right-hand content remain eligible for the fallback.

The existing single-command requirement remains in place.

Malformed MIDI commands and multiple-command buttons do not receive an automatic MIDI label.
