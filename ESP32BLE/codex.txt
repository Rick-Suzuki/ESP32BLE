F. EMPTY CELLS

Main_ButtonBehavior.swift lines 1596-1600.

A cell is empty only if:

• trimmed rawLine is empty
• sendTexts is empty
• alternate display text is empty

This means these remain occupied:

• button with command text
• SF Symbol-only button encoded in rawLine / alternate text
• image or hidden metadata encoded in rawLine
• invisible but occupied button
• continuation token

Blank placeholders are separately allowed.

I did not find a source path where a visually occupied normal button would be considered empty unless its parsed entry truly has no rawLine, no sendTexts, and no alternate text.

H. 3x3 ANALYSIS

For 3x3 to be enabled, at least one candidate anchor must satisfy all of this:

1. 3x3 is supported.
2. The selected index resolves to a valid button anchor.
3. The 3x3 rectangle fits inside grid dimensions.
4. All nine cell indexes are within visible bounds.
5. At least one of the nine cells overlaps the original selected button footprint.
6. Every non-source cell in the nine-cell footprint is blank placeholder or empty.
7. No other button anchor or continuation token appears in any non-source target cell.

Important:
The valid 3x3 candidate does not have to start at the selected button’s current top-left anchor. It may be above, left, or diagonally above-left as long as it overlaps the original button.
