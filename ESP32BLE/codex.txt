I. Recommended smallest coordinated correction

RECOMMENDED

1. Remove only the two MIDI selector panel border overlays.
   • Keep the existing shared Quick palette border.
   • The palette border is the outer, visible panel boundary.
   • This removes the known duplicate inner line without touching shared Quick geometry.
   • Do not change Files or Time.

2. Reallocate responsive width with priority for the control column.
   • Keep the 12-point root padding.
   • Reduce the label/control gap from 8 to 4 only in the MIDI helper.
   • Make the label column responsive: use up to 68 points when space permits, but allow it to contract before the control column falls below the preferred 120 points.
   • Use the resulting same control width for every shared Menu label, numeric selector, and Mode row.

3. Preserve the 120-point Mode width whenever the offered panel width allows it.
   • The responsive label column should yield width to the control column first.
   • If the panel is genuinely narrower than the combined requirements, the control must shrink rather than overflow.

4. Make action buttons resist wrapping without changing vertical position.
   • Keep the existing row and bottom placement.
   • Use one-line labels for only the two disabled MIDI action buttons.
   • Reduce row-only horizontal padding and/or the 12-point inter-button gap before changing font size or outer panel geometry.

LIKELY SUFFICIENT FOR THE TESTED DEVICE

Reducing the gap by 4 points and allowing the label column to contract by approximately 10–12 points should restore at least 120 points to the control column while preserving labels such as “cc type” and “toggle” at ordinary text size. Exact text-metric safety is not provable from source.
