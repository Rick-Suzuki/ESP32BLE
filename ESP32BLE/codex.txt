7. Declarations deliberately left behind

Left in ContentView.swift:

orientationState
ButtonClickFeedback
OutputMode

Reason:

AppRuntimeFlags / orientationState are app orientation support, not Mac connection manager support.

ButtonClickFeedback is used broadly by editor and UI controls.

OutputMode is shared app-level output routing state and is referenced by ContentView/MainScreen/Keyboard flows.

I also left the existing ContentView imports untouched. Network/CryptoKit/Security are no longer needed by the moved code there, but removing imports would be cleanup beyond the requested structural move.
