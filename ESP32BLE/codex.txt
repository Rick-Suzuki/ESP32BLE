3. Ordinary audio lifecycle tracking

playMainGridSound(named:repeats:volumePercentage:) now sets ordinarySoundActive when a valid request begins.

It remains active during:

• Audio-session activation
• Background player preparation
• Playback
• Future paused playback

It is cleared by current-request activation/preparation/playback failure, natural completion, or stopMainGridSoundPlayback().


4. Ordinary natural-completion delegate

Added MainGridSoundPlaybackDelegate in Main_ButtonBehavior.swift:21.

It implements audioPlayerDidFinishPlaying(_:successfully:) and forwards completion to MainActor.

Each delegate retains its originating sound request UUID. The completion handler clears activity only when that UUID still equals soundPlaybackRequestID.


5. Ambient activity tracking

MainGridAmbientSoundState now publishes read-only isPlaybackActive at Main_ButtonLabelView.swift:1385.

It becomes true when ambient activation/preparation begins and remains true during looping playback.

It becomes false when playback stops or the current activation, preparation, or play operation fails.


6. Speech activity tracking

speakMainGridText(_:) sets speechSynthesisActive after accepting a request and assigning its UUID.

Activity remains true through activation, queuing, and speech playback.

stopSpokenGridText() clears it synchronously.


7. Speech completion/cancellation delegate

Added MainGridSpeechPlaybackDelegate in Main_ButtonBehavior.swift:39.

It handles:

• speechSynthesizer(_:didFinish:)
• speechSynthesizer(_:didCancel:)

The delegate records both the speech request UUID and the expected AVSpeechUtterance identity. Only the matching utterance can report completion, and the MainActor closure additionally verifies speechPlaybackRequestID before clearing activity.

14. Request-ID and stale-callback protection

Ordinary completion handlers compare their captured request UUID with soundPlaybackRequestID.

Speech callbacks verify both utterance identity and speechPlaybackRequestID.

Ambient failure paths retain the existing playbackRequestID checks.

Old callbacks therefore cannot clear activity belonging to newer requests.


15. Failure-path handling

Current ordinary requests clear activity on:

• Audio-session activation failure
• Background preparation failure
• player.play() failure

Current ambient requests clear activity on:

• Missing file
• Activation failure
• Preparation failure
• player.play() failure

Current speech requests clear activity on activation failure.

Stale failures return without changing newer activity or displaying obsolete alerts.


16. Natural completion behaviour

Ordinary non-looping sounds clear activity through AVAudioPlayerDelegate.

Speech synthesis clears activity through AVSpeechSynthesizerDelegate.

Ambient playback loops indefinitely, so its activity ends through existing stop/replacement/failure paths.

No polling was introduced.
