4. How Home document resolution works

ContentView document selection:
ESP32BLE/Scrns/ContentView.swift
lines 2698-2727
Function: selectDocumentNamedFromGrid(_:)

Flow:
• canonicalDocumentFileName(from:) preserves names ending in .screen or .txt.
• Names without an extension default to .txt.
• It first searches documentFiles for an exact filename.
• If the requested filename ends in .txt and no exact match is found, it falls back to a .screen file with the same base name.
• It then calls selectDocument(fileURL, recordHistory: true).

Important detail:
documentFiles appears to be the preferred screen document list, so selectDocumentNamedFromGrid("home.txt") can still resolve to home.screen through the legacy fallback when home.screen exists.

5. Confirmed cause

There are two related issues:

First, the Main Screen top-left Home button does not currently open any document because its selection call is commented out.

Second, the remaining active Home command paths still use the legacy filename home.txt:
• grid/send-text token "home"
• speech command "go home"

Those legacy references rely on fallback logic to reach home.screen. That is fragile and produces legacy error text.

6. Other navigation paths affected

Affected:
• Top-left toolbar Home button: currently no document navigation.
• External keyboard shortcut "h": Main_Screen.swift lines 2518-2520 calls openHomeDocumentFromMainScreenControl(), so it has the same issue as the toolbar Home button.
• Grid action/send text "home": resolves to home.txt in Main_ButtonBehavior.swift.
• Speech command "go home": explicitly opens home.txt in SR_Support.swift.

Not affected:
• Explicit "home.screen" action text should already be accepted by targetDocumentNameForSendText(_:).
• Speech "open home.screen" should pass through targetDocumentNameForSpeechOpenCommand(_:) and select the .screen file if present.
• Generic .screen document creation/default mechanisms already use .screen.

7. Smallest safe correction

Recommended smallest correction:

A. In Main_Screen.swift, make openHomeDocumentFromMainScreenControl() call:
selectDocumentNamedFromGrid("home.screen")

Preserve the existing speechActive speak behavior.

B. In Main_ButtonBehavior.swift, change the special "home" token mapping from:
return "home.txt"

to:
return "home.screen"

C. In SR_Support.swift, change the "go home" speech path from:
selectDocumentNamedFromGrid("home.txt")

to:
selectDocumentNamedFromGrid("home.screen")

and update the matching error message to home.screen.

This preserves legacy .txt fallback elsewhere because selectDocumentNamedFromGrid and canonicalDocumentFileName do not need to change.
