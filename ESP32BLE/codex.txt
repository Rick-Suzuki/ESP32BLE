B. Canonicalization helper

canonicalSmartScriptKeycode(_:) uppercases a complete candidate only for comparison against the exact 17 supported dotted commands.

Recognized examples:

.up, .Up, .UP -> .UP
.sp, .Sp, .SP -> .SP
.ctc, .CtC, .CTC -> .CTC
.mc, .Mc, .MC -> .MC

It returns nil for every other token. There is no substring or prefix matching.

C. Application before output

sendKeyboardOutputTokens now:

1. Preserves existing normalization.
2. Replaces a recognized Smart Keycode with its canonical uppercase token.
3. Removes unknown dotted tokens as before.
4. Preserves non-dotted text unchanged.

Thus canonical dotted commands now reach the existing Mac Smart Script sender or BLE line sender.
