CURRENT LAYOUT REQUIREMENTS

• Main:
Main grid scales to available width. Bottom toolbar uses ViewThatFits, and iPhone-specific compact controls already exist. Not the limiting layout.

• Keyboard:
Keyboard grid scales to available width. Top row has several fixed controls, but physical testing says it is basically good. Not the limiting layout.

• Editor:
Soft editor clamps top row width to available geometry and is physically viable. It is dense but not currently the width gate.

• Settings:
Settings top toolbar is the limiting layout. After the final button reductions, estimated practical minimum is roughly 728-735 pt usable width, depending on actual SF Symbol menu intrinsic widths.

Most width-demanding layout:
Settings top toolbar.

Reason:
It is the only major iPhone layout that is still a single horizontal toolbar with many fixed/minimum-width controls: Main, voice menu, speed slider, 140-title plus padding, import/export icons, Screens, Repair, New, HStack gaps, and toolbar padding.

RECOMMENDED MINIMUM IPHONE USABLE WIDTH

Recommended threshold:
730 pt usable landscape width.

Reason:
• It accepts iPhone 17-class usable width of about 750 pt.
• It rejects iPhone SE 3 usable width of 667 pt.
• It is based on actual available layout space, not model names.
• It leaves about 15-20 pt margin below the working iPhone 17 usable width.

Safety margin:
Small but sensible for this UI. I would not set it lower than 720; 730 is the cleaner boundary.

RECOMMENDED SWIFT MEASUREMENT

Use safe-area-adjusted landscape width:

usableWidth = geometry.size.width - geometry.safeAreaInsets.leading - geometry.safeAreaInsets.trailing

Compare that to the threshold only when !isPad.

This describes the horizontal space ESP can actually use, independent of iPhone model name. The future “Screen Too Small” gate could live cleanly near the top-level ContentView GeometryReader, before presenting KeyboardScreen, MainScreen, or SettingsScreen.

Do not gate by UIScreen.main.bounds.width alone; raw bounds includes unsafe side areas on modern iPhones.
